# Каменный легион

Шахматы для двоих на одном устройстве (компьютер или телефон): «Время приключений» против «Рика и Морти». Фигуры — расписная глянцевая керамика в цветах персонажей на мраморных постаментах: белый мрамор с золотом у светлых, чёрный с платиной у тёмных. Доска из клёна и ореха. При взятии фигуры сражаются, сбитая раскалывается на осколки, а за каждую срубленную фигуру показывается интересный факт.

- Полные правила: рокировка, взятие на проходе, превращение пешки, шах, мат, пат, ничьи
- Доска поворачивается к игроку, который ходит (можно выключить)
- Отмена хода, автосохранение партии в браузере
- Две детализации моделей: `hi` для компьютера, `lo` для телефона (выбирается автоматически)

`index.html` — вся игра, 3D на [three.js](https://threejs.org/) r128 с CDN. Сборка не нужна.

## Модели

Фигуры — SDF-скульптуры: каждая описана в `tools/sculpt/chars3.js` как одна математическая форма с плавным слиянием частей и резьбой, затем превращается в полигоны (`mesher.js`, Surface Nets) с запечённым затенением.

Пересобрать игровые модели (Node.js):

```bash
cd tools/sculpt
GAME=1 node export.js ../../models AT:w,RM:b hi:.0095,lo:.015
```

У каждой вершины свой цвет — индекс в `models/palette.json` (цвет и вид: глазурь, металл или свечение).

Формат `.bin` v3: `[u32 вершин][u32 индексов][u32 16-битные индексы][u32 версия=3]`, позиции Uint16 в кубе x,z ∈ [-0.5, 0.5], y ∈ [-0.05, 1.6], затенение Uint8, индекс цвета Uint8, индексы.
