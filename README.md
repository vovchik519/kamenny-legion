# Каменный легион

Шахматы для двоих на одном устройстве (компьютер или телефон). Каждая фигура — свой каменный воин в 3D: копейщики, всадники, боевые маги, каменные стражи, воительница и король. При взятии воины сражаются, а сбитая фигура разлетается на осколки. За каждую срубленную фигуру показывается интересный факт.

- Полные правила: рокировка, взятие на проходе, превращение пешки, шах, мат, пат, ничьи
- Доска поворачивается к игроку, который ходит (можно выключить)
- Отмена хода, автосохранение партии в браузере

Один статический файл `index.html`, 3D на [three.js](https://threejs.org/) r128 с CDN. Сборка не нужна.
